<br>

One purpose of this case study is to demonstrate that not all OCR tools are the same, and they don’t all fit with archival ethics in the same way. Evaluation of different OCR tools against the archival ethics framework demonstrates important qualitative differences - there are technical performance metrics we can look at to evaluate a tool against practical data, like accuracy percentages, processing speeds, and file size outputs, but assessing a tool more qualitatively against professional values helps highlight the ethical considerations that inform responsible technology adoption. 

We can go back to our four sets of archival values, starting with authenticity and transparency. LLM models consistently generated plausible but fabricated text, and inserted text into outputs that had nothing to do with the text on the page - distractions and hallucinations. In some settings, these kinds of errors are perfectly fine, but in an archival setting, authenticity is preferred. Tools like Opticolumn generated imperfections that were recognizable: not only text accurate to the original, but clearly misread characters, garbled words, and text fragments - all transparent errors. Opticolumn also clearly documents its training data, can explain recognition methods, reproduce consistent results each time, and trace error sources. 

In terms of access and equity, LLM tools performed better on poor-quality documents, generating “readable” text from challenging sources, and sometimes faster than other options. An institution has to determine whether access benefits from these performance advantages are worth the authenticity risks. But if there is capacity, NN tools can greatly enhance access and with far more recognizable errors.

<br>

And LLM tools do not necessarily support sustainable archival workflows. LLM tools can ease workflows and often don’t require a huge investment of time and expertise just to get started, but they lead to dependencies on external services and opaque processes. Working with tools like Opticolumn required technical investment, staff time, institutional resources, and so on, but it helped to grow institutional capacity, expanded staff expertise, and resulted in a tool that can be openly maintained, modified, and used by anyone. These are important elements of archival sustainability.

<br>

No single OCR tool serves all archival needs. LLM tools offer genuine advantages in certain contexts, particularly for institutions that lack technical capacity or have very challenging source materials. But for institutions that have the capacity, NN approaches align better with archival ethics, allowing for more authentic, transparent, and sustainable OCR of archival materials. Each institution has to make a decision based on their own context.
